# 信息架构（原型层）

> 这是"东西摆在哪、用户怎么走"的一层。当前界面以 `src/App.vue` 为唯一入口（单页无路由），
> 本文先如实记录**现状**，再给出**目标结构**与迁移步骤。状态：v0.1 提案。
>
> 关联：[产品定义](../PRODUCT.md) · [设计系统](DESIGN-SYSTEM.md) · [功能规格](FUNCTIONAL-SPEC.md)

## 2. 目标结构（v0.2 建议）

```
应用
├── 工作台（默认）
│   ├── 顶栏：模式 · 撤销 · ＋（加卡/命令） · 更多 ▾
│   ├── 画布（12/8/6/4/1 投影）
│   └── 浮出指示条：「已浮出 3 张 · 管理」
├── 布局编辑
│   ├── 模块库（搜索 / 分类 / 最近使用）
│   └── 画布 + 批量操作
├── 设置（独立入口，不再叫「外观」）
│   ├── 通用（语言、启动行为、托盘）
│   ├── 外观（皮肤 / 明暗 / 密度）
│   ├── 数据与备份（自动备份、导出、恢复）
│   ├── 桌面与快捷键
│   ├── 关于与更新
│   └── 实验室（AI、同步 —— 默认关闭）
├── 浮窗管理（新）
├── 命令面板（保留，顶栏 ＋ 里也有一项）
└── 托盘
```

### 顶栏收敛

现状 8 组控件（模式、宽列状态、编辑事务、撤销重做、排布、模板、外观）→ 目标 4 组：

| 位置 | 内容 | 理由 |
|---|---|---|
| 左 | 品牌 + 模式切换（工作台 / 布局编辑） | 位置固定，肌肉记忆 |
| 中 | 编辑态才出现：取消 / 保存 + 改动数 | 只在需要时占位 |
| 右 | 撤销 / 重做 · ＋ · 更多 | 「＋」同时是加卡与命令面板入口，解决 Ctrl+K 不可发现 |
| 「更多」内 | 排布、模板、外观、设置、关于 | 低频操作下沉，但**设置必须有独立入口**（不能只藏在「更多」） |

## 3. 核心流程（含失败路径与空状态）

### 3.1 首启
1. 无存档 → 载入 `general` 模板 + 示例内容 → 弹模板选择器（可跳过）。
2. **目标增补**：3 步引导（选模板 → 拖一张卡 → 试 Ctrl+K），可"不再提示"。
3. 失败路径：读盘失败目前会被当成"文件不存在"并回写 localStorage（见功能规格 R-04），
   目标行为是**保留现场、提示用户、不覆盖**。

### 3.2 加卡 → 配置 → 保存
1. 进入布局编辑 → 模块库拖入 / 「全部卡片」点选 → 自动找空位。
2. 卡片内容直接编辑（即时落盘）；布局改动计入"改动数"。
3. 「保存」= 刷新编辑基线；「取消」= 回滚到进入编辑前的快照（有二次确认）。
4. **目标增补**：同种卡可多实例（当前 `store.ts` 的 `available` 只列未放置卡）。

### 3.3 浮窗
1. 卡片按钮 / 命令 → Rust 建无边框置顶窗，几何记忆在 `floatwin.rs`。
2. **缺口**：浮出后从工作台投影消失，无清单、无标识；目标见 §4。

### 3.4 备份与恢复
1. 设置 → 导出 JSON（版面 + 方案 + 四类内容）。
2. 恢复先显示包内摘要再确认；布局可撤销、内容不可。
3. **目标**：备份覆盖全部数据 key + 自动备份 + 恢复可撤销（见功能规格 F-03/F-04）。

### 3.5 更新
手动检查 → 下载 → minisign 验签 → 重启安装；网页版只给下载页。保留。

## 4. 状态清单（每个界面都要有）

| 状态 | 现状 | 目标 |
|---|---|---|
| 空（无卡） | 一句话 | 行动按钮（加卡 / 套模板） |
| 空（无搜索命中） | 无 | 提示 + 清除筛选 |
| 加载 | 卡片懒加载占位 | 统一骨架屏 |
| 错误（存储） | 红条 | 保留 + 可重试 + 指引到备份 |
| 错误（网络卡） | 分散 | 卡片内统一错误态 + 重试 |
| 离线 | 无区分 | 联网卡显示"离线，最后更新于 …" |
| 锁定 | 有 | 保留 |
| 窄屏 | 工作台可用、编辑退化 | 编辑仍可加卡（列表式） |
| 浮出 | 无提示 | 工作台指示条 + 管理面板 |

| 方向键 / `Shift`+方向 | 移动 / 缩放 | 有 |
| `Enter` | 切换形态 | 有 |

| `Delete` | 回库 | 有 |
| `Ctrl+A` | 全选 | 有 |
| `Esc` | 逐层退出（面板→确认框→局部选择→取消编辑→弹层） | 有 |
| `Ctrl+Enter` | 行重排 | **命令表标了但无实现**（`commands.ts:253`） |

## 6. 迁移步骤（按依赖排序）

1. 顶栏收敛 + 「＋」入口（纯前端，低风险）。
2. 设置独立入口 + IA 分组（纯前端）。
3. 浮窗指示条 + 管理面板（需要浮窗状态聚合）。
4. 模块库搜索 / 分类 / 最近使用（数据可先本地记录）。
5. 首启引导（可 A/B，先做可跳过版本）。
6. 窄屏编辑补"加卡"（与多实例卡一起做更划算）。
