## 1. 对象模型

| 对象 | 内容 | 存储 | 实现 |
|---|---|---|---|
| `LayoutDoc` | `items[]`：id / variant / x / y / w / h / locked / title；`rows[]`（行容器） | `modulo.layout.v1` | `src/vue/store.ts`、`packages/engine/src/types.ts` |
| `CardData` | 各卡的内容与配置（便签、待办、速记、记账、订阅、自选…） | `modulo.carddata.v1` | `src/vue/cardData*.ts`（2026-10-20 拆五份） |
| `SchemeBook` | 版面方案册（另存 / 覆盖 / 排序 / 应用） | `modulo.schemes.v1` | `src/vue/useSchemes.ts` |
| `Settings` | 外观、桌面壳行为、模板、AI 设置 | `modulo.appearance.v1` / `shell.v1` / `template.v1` / `ai-settings.v1` | `src/vue/fileStorage.ts` |
| 会议/截图/AI 历史 | 独立目录与索引 | `meetings/`、`shots/`、`ai/history.json` | `src-tauri/src/{meeting,capture,ai}` |
| 浮窗几何 | 已浮出的卡与位置 | `detached.json` | `src-tauri/src/floatwin.rs` |
| 备份包 | layout + schemes + cardData | 用户导出 JSON | `src/vue/backup.ts`（`BACKUP_VERSION=1`） |

**键到文件的映射**：桌面 `%APPDATA%\app.modulo\data\<key>.json`（`src-tauri/src/storage.rs`），
网页 `localStorage`（`src/vue/fileStorage.ts`）。写入是"临时文件 + rename"的原子写。

## 3. 缺口与验收（P0 = 产品可用性底线）

### F-01 同种卡多实例（P0）
- **现状**：`store.ts` 的 `available` 只列未放置卡 ⇒ 一个待办清单、一个时钟、一块看板。
- **分两阶段**（2026-10-20 实现时发现的约束：`CardData` 是**单例结构**——一个 `todos`、
  一个 `sticky`，卡组件靠 `inject(cardData)` 共享，并不是按卡 keyed）：
  - **阶段 1（已落地）**：版面层多开。实例 id 与模块 id 分离（`module` 字段），
    第二张起用 `模块:2`；两个实例**共享同一份内容**（两个待办卡 = 同一清单的两个视图）。
    已验：引擎 `addItem(instanceId)`、`moduleIdOf` 贯穿投影/校验/行折叠/缩放/形态、
    浮窗按实例读模块、模块库不再隐藏已放置卡。
  - **阶段 2（待做）**：把记录类卡（便签/待办/速记/记账/四象限/习惯/倒数日）的数据
    按实例拆开，卡组件从 `inject(cardData)` 改为"按实例取切片"，并做数据迁移。
- **阶段 1 验收（已满足）**：
  1. 同一模块放两张，id 为 `模块` 与 `模块:2`，第二个实例带 `module` 归属（单测）；
  2. 旧存档/模板/单实例的形状逐字不变（第一实例不写 `module`，序列化/投影输出不变）；
  3. 折叠→展开、缩放、切形态、浮窗都能正确解析模块（引擎与行容器单测覆盖）。
- **阶段 2 验收（待做）**：两个实例内容互不影响；数据迁移夹具 v1→v2 roundtrip；
  命令面板能定位到**正确实例**；备份导出/恢复两实例都在。

### F-02 内容级撤销（P0，✅ 已落地 2026-10-20）
- **现状（改造前）**：撤销只覆盖版面（`store.ts` 历史栈），便签/待办/速记/记账误删不可恢复。
- **落地**：`src/vue/contentHistory.ts` —— `CardData` 整份快照 + 环形 50 步；
  一段连续输入按 500ms 窗口合并成一步；撤销/重做整份回填且保留顶层 reactive 对象。
  App 的 `undoLatest()` 按时间戳路由：编辑态撤版面、工作台态撤内容，一边没得撤退到另一边；
  输入框内不拦 Ctrl+Z（保留浏览器原生撤销）。
- **验收（已满足）**：
  1. 删除一条待办 → `Ctrl+Z` 恢复，再 `Ctrl+Shift+Z` 再删（`tests/vue/contentHistory.test.ts`）；
  2. 连续输入 1 秒内合并为一条历史（同上「一段连续输入合并成一步」）；
  3. 历史上限（50）生效，新改动清空重做栈；
  4. 直接赋值与数组变更都被记录（覆盖 `v-model` 路径）；
  5. 撤销/重做不制造新历史（不会套娃）。
- **未做**：写入防抖（深监听仍每改必写盘）—— 与 E2E「输入后立刻刷新」有竞态，单独一笔。

### F-03 完整备份（P0）
- **现状**：包内只有 layout / schemes / cardData 的四个内容类型；`appearance`、`shell`、
  `template`、截图、会议、AI 历史都不在；**密钥类设置不得导出**。
- **目标**：默认包覆盖"恢复后应用看起来和用起来一样"所需的全部**非敏感**配置；
  截图/会议作为可选大项；密钥永不入包。
- **验收**：
  1. 导出后在全空环境恢复，皮肤/密度/托盘行为/布局/方案/内容一致（逐键 diff）；
  2. 包内不含任何 token / API key（单测扫描序列化结果）；
  3. 版本升级后旧备份仍可导入（`BACKUP_VERSION` 迁移夹具）。

### F-04 自动备份（P0）
- **目标**：每日首次启动 + 恢复前 + 版本升级前各一份，保留 7 份，落在
  `%APPDATA%\app.modulo\backups\`；失败不阻塞启动但要在设置里可见。
- **验收**：伪造时间推进触发一次（注入时钟）；旋转保留 7 份；恢复入口能列出并预览；
  备份写失败时 UI 有明确提示且不影响正常写盘。

### F-05 提醒与系统通知（P0）
- **现状**：全仓无 notification 能力；倒数日/生日/习惯/待办只能"看"。
- **目标**：到点系统通知 + 卡内角标；支持静默时段；同一事件去重。
- **验收**：注入"now"跨越到期点 → 恰好一条通知；重启后不重复；静默时段内不弹；
  通知点击回到对应卡（深度链接）。

### F-06 数据迁移框架（P0，技术债）
- **现状**：`SCHEMA_VERSION=1`、`MIGRATIONS` 空表、`cardData` 无版本；加 `rows` 时未升版。
- **目标**：每个 key 独立版本 + 迁移表；迁移前自动备份；失败回滚并保留现场。
- **验收**：夹具 v1 → v2 迁移后再读回一致；迁移抛错时原文件不被破坏；CI 有迁移测试。

### F-07 网络策略单一来源（P0，安全）
- **现状**：允许/拒绝清单在 `packages/engine/src/watch.ts`、`src-tauri/src/net.rs`、
  `tauri.conf.json` 的 CSP、AI 白名单四处；已漂移（超时 5s vs 10s；CSP 缺东财）。
- **目标**：一份 `net-policy.json` 生成三处（引擎清单 / Rust 清单 / CSP），CI 断言一致。
- **验收**：改一处，三个消费方同步；任一不一致 CI 红；股票卡在桌面能实际取数。

### F-08 浮窗清单与标识（P1）
- **验收**：工作台显示"已浮出 N 张"；管理面板可收回/置顶/定位；浮窗关闭后标识消失。

### F-09 模块库搜索/分类/最近使用（P1）
- **验收**：54 张卡可按关键词与分类检索；最近使用置顶；无命中时有空状态。

### F-10 设置 IA + 首启引导（P1）
- **验收**：设置独立入口；六个分组；首启三步可跳过；"不再提示"可复位。

### F-11 安全收口（P1）
- **验收**：`launcher` 不再放行 UNC；未接线的 AI 命令要么有调用点、要么删除（CI 断言命令面与调用点一致）；
  命令注册与能力声明一致。

## 4. 非功能需求

| 类别 | 要求 | 现状 |
|---|---|---|
| 启动 | 冷启动到可交互 ≤ 1.5s（本机基线待测） | 未建预算 |
| 交互 | 拖拽每帧不重排版面 | 已有 `drag:budget` 门禁 |
| 写入 | 内容改动防抖 ≤ 300ms，避免每键写盘 | 现状每改必写（`cardData.ts` 深监听） |
| 内存 | 常驻 ≤ 300MB（20 张卡） | 未建预算 |
| 可靠性 | 读盘异常不得被当成"空数据"回落到 localStorage | 现状：读失败即置 `null`，若有 legacy 值会回写（`fileStorage.ts:113-126`）；磁盘已有数据时这是覆盖风险 |
| 隐私 | 无遥测上传；密钥只进钥匙串/本地文件，永不进备份 | 现状密钥未入备份，但 AI 命令面未接线 |
| 安全 | 网络策略单源、无 UNC、命令最小权限 | 见 F-07/F-11 |
